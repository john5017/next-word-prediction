# Next Word Prediction using LSTM

## Project Overview
This project predicts the next word based on user input using
Natural Language Processing (NLP) and an LSTM neural network.

## Technologies Used
- Python
- TensorFlow / Keras
- NLTK
- NumPy
- Google Colab

## Dataset
Sherlock Holmes text from Project Gutenberg.

## Features
- Text preprocessing and tokenization
- LSTM-based next-word prediction
- Top-5 predicted words with probabilities
- Accuracy, Precision, Recall, F1-score and Top-5 Accuracy
- Manual user input for prediction

## How to Run
Open the notebook in Google Colab and execute the cells in order.
